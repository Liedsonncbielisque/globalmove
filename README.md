# 🌎 GlobalMove

**Transforme o sonho de morar fora em um plano.**

Plataforma inteligente de planejamento migratório internacional que ajuda você a descobrir:

- 🌎 Para onde pode ir
- 💰 Quanto precisa
- 📅 Quando consegue ir
- 🏠 Onde pode morar
- 🛂 Quais rotas migratórias são compatíveis
- 💼 Onde seu perfil profissional tem melhores oportunidades
- 📈 Quanto precisa economizar
- ⚖️ Qual destino apresenta o melhor equilíbrio
- 🚀 Qual deve ser seu próximo passo

## 🚀 Stack

### Frontend
- React 18+
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- React Router
- TanStack Query
- Recharts
- Lucide Icons

### Backend
- Node.js 20+
- TypeScript
- Fastify
- Prisma ORM
- PostgreSQL (Supabase)
- Redis (cache)
- JWT

### Infraestrutura
- Docker
- Docker Compose
- GitHub Actions
- Nginx

## 📦 Instalação

```bash
# Clone o repositório
git clone https://github.com/Liedsonncbielisque/globalmove.git
cd globalmove

# Instale dependências
npm install

# Configure variáveis de ambiente
cp .env.example .env

# Inicie com Docker
docker-compose up -d

# Ou inicie manualmente
cd backend && npm run dev
cd frontend && npm run dev
```

## 🌐 Acesso

- Frontend: http://localhost:5173
- Backend: http://localhost:3001
- API Docs: http://localhost:3001/docs
